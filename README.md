## O que é este repositório?

Este é o meu diário de bordo do bootcamp **Python para Análise e Automação de Dados**.
A trilha mistura Python, SQL com copilotos, bibliotecas de dados e IA generativa, e termina com a construção de um **assistente virtual com IA**.

Aqui eu guardo o que vou praticando pelo caminho: **exercícios dos cursos, desafios de código e projetos de portfólio**.

## Como rodar na sua máquina

Basta ter o **Python 3** instalado. No terminal, a partir da raiz do projeto:

```bash
python praticas/[topico]/[nome_do_arquivo].py
```

Exemplo:

```bash
python praticas/operadores/operadores_logicos.py
```
